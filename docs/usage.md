# TD4 操作ガイド

[READMEへ戻る](../README.md) ／ [設計・実装仕様](architecture.md) ／ [ネットリスト](netlist.md)

TD4 Web Emulatorの画面操作を説明します。CPU内部の命令処理や物理端子の接続関係は、それぞれ設計・実装仕様とネットリストを参照してください。

## はじめに

1. [エミュレータ](https://naoiw.github.io/td4/) を開き、サンプルプログラムを選ぶか、PROGRAM EDITORでコードを入力します。
2. 必要に応じて「ROMに書き込む」を押し、**電源ON**で実行します。投入直後はPC=0x00を示し、最初のクロック立ち上がりから命令を実行します。
3. **停止／実行**でCPUの進行を切り替え、基板のICやLOGIC ANALYZERで信号を確認します。

## 電源・クロック・実行制御

- 画面上部と基板上の電源操作が連動します。電源ON時はCPUが自動で実行を開始し、基板のCRクロック切替で **2Hz／10Hz** を選択できます（初期値は2Hz）。
- CPUを停止しても給電状態を維持し、ICやOUTPUT LEDの表示を観察できます。ROM書込み・ROMビット編集・ブレークポイント到達時もCPUだけ停止します。
- **Spaceキー**でもCPUの実行／停止を切り替えられます（電源ON中のみ）。テキスト入力中、フォーム操作中、ボタンやリンクにフォーカスがあるときは、通常のキー操作を優先します。長押しによる連続切替はしません。
- **電源OFF**でCPUの揮発状態と実行・波形履歴を初期化します。ROMの内容とINPUTスイッチの設定は保持します。
- **CYCLES**は実行した命令数を6桁で表示します。ROM側のブレークポイントを切り替え、「BPを解除」でまとめて解除できます。

## 基板とIC詳細

- 基板には13個の74HC ICを機能別に配置しています。左列がCLOCK / CONTROL、MUX / ALU、REGISTERS、中央がROM / FETCH、右側がPOWER / CLOCK・ROM・INPUT / OUTPUTです。
- ICをクリックすると、基板の下に**入力・出力の詳細と各信号のH/L**を表示します。詳細内の信号プローブを選ぶと、同じネットの端子や基板部品を強調表示します。
- IC詳細画面の表示中に**Escキー**を押すと詳細を閉じ、元のICにフォーカスが戻ります。詳細を開いていない状態で実行中なら、Escキーは従来どおりCPUを停止します。
- DIPの物理端子と、IC詳細画面の論理プローブは別表示です。物理端子のH/Lは緑／灰色、VCCは給電時に赤、GNDは黒、未モデル化端子は暗灰色を使います。選択ネットの強調色はHIGHがオレンジ、LOWが淡い黄色です。
- 緑レジスト風の基板は表示領域の幅に合わせて拡大・縮小されます。ICやROMスイッチの縦横比は保たれます。

ICの内部論理・機能プローブの構成は[設計・実装仕様](architecture.md)、実ピン番号と接続は[ネットリスト](netlist.md)を参照してください。

## ROMと4bit入出力

- **16×8bit ROM**：基板上のDIPスイッチは16組を4×4に配置し、各組はD7〜D0の8bitです。PROGRAM ROMからもビットを編集できます。
- **実行位置**：番地ラベルは `0x0`〜`0xF`。現在のPCやブレークポイントをPROGRAM ROMで確認でき、基板上の選択LEDは現在選択中のアドレスを示します。
- **INPUT / OUTPUT**：ROM下に4bit入力スイッチと4bit出力LEDがあります。スイッチは入力レジスタに、LEDはCPUの出力状態に対応します。

## プログラムの編集

- 画面上部のサンプルカードまたはPROGRAM EDITORの選択欄からプログラムを読み込めます。用意されているサンプルは9種類です。
- PROGRAM EDITORでアセンブリ／RAW HEXを入力し、**「ROMに書き込む」**でCPUのROMへ反映します。
- ROMビットを直接変更した場合は、**「ROM → ソース」**で現在のROM内容をソース欄へ取り込めます。
- ROMの `.bin` ファイルを保存・読み込む機能はありません。

## サンプルプログラムの動作

| サンプル | 主な動作 |
| --- | --- |
| **LEDスキャナ** | LED0→1→2→3→2→1の順に点灯し、折り返しで全消灯を2クロック保持します（8命令）。 |
| **2進パターン** | LED出力が `1→3→7→F→7→3→0` と変化します。最後の0をジャンプ実行中も保持します（8命令）。 |
| **2bit加算（16命令）** | `SW1:0` と `SW3:2` をそれぞれ2bitの値として加え、3bitの答えを `LED2:0` に表示します。LED3は消灯します。 |

### 2bit加算（16命令）の使い方

1. PROGRAM EDITORのサンプル選択欄、または画面上部のサンプルカードから「2bit加算（16命令）」を選択します。
2. `SW1`・`SW0` で1つ目の数（0〜3）、`SW3`・`SW2` で2つ目の数（0〜3）を設定します。
3. 電源をONにし、`LED2`・`LED1`・`LED0` を確認します。**LED2は2bit加算の桁上がり**です。例えば `SW3..0=1011`（2+3）の結果は `LED2..0=101`（5）になります。

入力はループの先頭で1回取得します。入力変更の反映には**9〜12クロック**（10Hzで約0.9〜1.2秒、2Hzで約4.5〜6秒）を要します。変更時点によっては次の入力取得までさらに待ちます。電源投入直後は初回の `OUT B` 実行まで出力が更新されません。

## LOGIC ANALYZERとEXECUTION TRACE

- LOGIC ANALYZERでは、基本信号・入出力・レジスタA/B・PC / ALU・ROMの5グループから選び、一度に最大10信号のH/Lを観察できます。空きチャンネルは `-` と `×` で表示します。
- 履歴は直近 **80サンプル**。通常は電源ON中に約20ms間隔で取得し、CPU停止中も一定値の波形を表示します。INPUT切替時は変化点を即時に記録します。
- **「波形を消去」**またはグループ変更で波形をクリアできます。実行した命令はEXECUTION TRACEに記録され、履歴欄の中をスクロールできます。
- 開発者向けにはコンソールから `TD4WaveCapture.setMode('oscilloscope')`（既定）と `TD4WaveCapture.setMode('cpu')` を切り替えられます。後者ではCPU停止中に履歴を更新しません。

## TD4命令セット一覧

- 画面下部の「TD4 命令セット」を開くと、**オリジナルの12命令**を機械語の上位4bit／下位4bit、キャリーフラグ（実行後）、SelB・SelA・Ld0〜Ld3のH/L信号、命令の説明と並べて確認できます。
- 即値指定の命令では下位4bitに `i3`〜`i0` を表示し、それ以外の標準命令では下位4bitはすべて0です。`0x3n` などの `n` は4bit即値を表します。
- Ld0〜Ld3はA・B・OUT・PCの**アクティブLOW**のロード制御です。JNCだけは実行前のCフラグによりLd3が切り替わり、C=0ならLOW（分岐する）、C=1ならHIGH（分岐しない）になります。
- キャリーの一覧は**実行後**の値です。ADD A/Bは桁あふれで1になり、そのほかの標準命令は0になります。JNCの条件判定は実行前のCを参照します。
- 画面幅に応じて一覧の文字・セル幅を調整します。狭い画面では1命令ごとにビット列と制御信号を折り返して表示し、**横スクロールなし**で確認できます。

## シミュレーションの範囲

本アプリは**CPU命令と理想論理値**を模擬します。電圧、ICの伝搬遅延、グリッチ、スイッチのチャタリング、CR発振のアナログ波形は計算していません。画面の端子配置は、実際の基板配線やパッケージの幾何配置を保証するものではありません。
