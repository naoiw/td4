## 参照と採用方針

- 添付 `TD4.pdf`（2021年KiCad回路図。p.1 CPU / p.2 ROM / p.3 CLOCK/RESET）
- https://xyama.sakura.ne.jp/hp/4bitCPU_TD4.html
- `src/core/ic-circuit.ts`・`src/core/signals.ts`（`develop`）

添付PDFと参考ページはROMのアドレス選択に **74HC138×2** を使用するが、オリジナルTD4は **74HC154×1**。本アプリは既存UIどおり **74HC154×1** を採用する。ROMスイッチは16組×8bit、出力には74HC540を使用する。

`U番号` はリポジトリの現行コードに従う。PDFとは一致しないので、以下の部品型番を照合して読み替える。

## 直結する主要ネット

`U.pin` は**ICの物理ピン番号**。bitの並びはすべて下位bit=0。

| ネット | 接続先 |
| --- | --- |
| `CLK` | **U2.6（74HC14 Cゲート出力）** → U3/U4/U5/U6.2, U1.11 |
| `RST_N` | U3/U4/U5/U6.1, U1.13（アクティブLOW。74HC14のU2.10は使用しない） |
| `PC0..PC3` | U6.14/.13/.12/.11 → U13.23/.22/.21/.20 |
| `A0..A3` | U3.14/.13/.12/.11 → U7.6/.10, U8.6/.10 |
| `B0..B3` | U4.14/.13/.12/.11 → U7.5/.11, U8.5/.11 |
| `IN0..IN3` | INPUTスイッチ → U7.4/.12, U8.4/.12 |
| `MUX0..MUX3` | U7.7/.9, U8.7/.9 → U9.5/.3/.14/.12 |
| `D0..D3` | U12.11/.12/.13/.14 → U9.6/.2/.15/.11（加算器B入力） |
| `ALU0..ALU3` | U9.4/.1/.13/.10 → U3/U4/U5/U6 の各.3/.4/.5/.6 |
| `OUT0..OUT3` | U5.14/.13/.12/.11 → OUTPUTポート、LED表示（LEDは抵抗経由） |
| `COUT` | U9.9 → U1.12（74HC74のB側D入力） |
| `C_N` | U1.8（74HC74のB側 /Q）→ U10.4（74HC32 Bゲート） |
| `D6_N` | U11.12（74HC10 Aゲート出力）→ U10.12, U11.4 |
| `JUMP_OR` | U10.6（74HC32 Bゲート出力）→ U11.11 |
| `SEL_A` | U10.3（D4 OR D7）→ U7/U8.14 |
| `SEL_B` | D5 → U7/U8.2 |
| `LOAD_A_N` | U10.8 → U3.9 |
| `LOAD_B_N` | U10.11 → U4.9 |
| `LOAD_OUT_N` | U11.6 → U5.9 |
| `LOAD_PC_N` | U11.8 → U6.9 |

同じ `ALU0..3` の4本は、A/B/OUT/PCすべての74HC161のD0..D3につながる。書き込まれる先は各ICの `LOAD_*_N` によって決まる。A/B/OUTの74HC161はENP(7)・ENT(10)をGND固定し、PCのU6は両方VCCに接続して通常カウントを可能にする。

74HC153×2は `1E#(1)`・`2E#(15)` をGND固定。各4:1入力の `I0=A`、`I1=B`、`I2=INPUT`、`I3=GND` を選ぶ。選択線は `S0(14)=SEL_A`、`S1(2)=SEL_B`。

## 74HC32・74HC10 デコード回路（PDF p.1 を正本）

添付PDFでの **U7=74HC32、U2=74HC10** は、アプリではそれぞれ **U10、U11**。
PDFのシンボルA/B/C/Dは**1個のパッケージ内のゲート番号**であり、別ICではない。
各端子の電気的直結先は `src/data/netlist.json` の `pinNets` / `nets` に登録し、
`gateGroups` がIC詳細画面の区画・入力・出力の物理ピン番号を決める。

### 74HC32（アプリU10、PDF U7）：OR 4ゲートすべて使用

| ゲート | 入力端子とネット | 出力端子とネット | 論理 |
| --- | --- | --- | --- |
| A | 1=`D7`, 2=`D4` | 3=`SEL_A` | D7 OR D4 |
| B | 4=`C_N`, 5=`D4` | 6=`JUMP_OR` | C_N OR D4 |
| C | 9=`D6`, 10=`D7` | 8=`LOAD_A_N` | D6 OR D7 |
| D | 12=`D6_N`, 13=`D7` | 11=`LOAD_B_N` | D6_N OR D7 |

### 74HC10（アプリU11、PDF U2）：NAND 3ゲートすべて使用

| ゲート | 入力端子とネット | 出力端子とネット | 論理 |
| --- | --- | --- | --- |
| A | 1=`VCC`, 2=`VCC`, 13=`D6` | 12=`D6_N` | NAND(1,1,D6)=NOT D6 |
| B | 3=`VCC`, 4=`D6_N`, 5=`D7` | 6=`LOAD_OUT_N` | NAND(1,D6_N,D7) |
| C | 9=`D6`, 10=`D7`, 11=`JUMP_OR` | 8=`LOAD_PC_N` | NAND(D6,D7,JUMP_OR) |

電源ピンは各ICとも7=GND、14=VCC。`D6_N` と `JUMP_OR` は
**IC内部の論理演算で生成される別々の中間電気ネット**。
入力と出力を同一ネットとして扱わず、74HC10 Aの12番出力からU10.12／U11.4へ、
74HC32 Bの6番出力からU11.11へ接続する。

アプリのCPU命令処理自体は変更せず、`levels()` がこの2本の中間信号を
理想論理値として計算する。信号選択時、PDFで直結した物理端子だけを同じ色で強調する。

## 74HC14 自動CR発振回路（今回の採用構成）

添付回路図のU13B/U13Cは、アプリではU2（74HC14、6回路入り）のB/Cに読み替える。抵抗やコンデンサはネットリストの電気的直結として扱わない。

| U2のゲート | 物理端子 | ネット | 役割 |
| --- | --- | --- | --- |
| B入力（2A） | 3 | `OSC_IN` | R6を経たCR発振のシュミット入力 |
| B出力（2Y） | 4 | `OSC_INV` | 発振信号の反転出力、R9/R10による抵抗帰還側 |
| C入力（3A） | 5 | `OSC_INV` | B出力から直結、波形を再整形 |
| C出力（3Y） | 6 | `CLK` | Bの出力を再反転して全CPUへ供給。C14経由で発振側へ容量帰還 |

- 直結は **U2.4 — U2.5**、**U2.6 — U1.11/U3.2/U4.2/U5.2/U6.2**。U2.3は `OSC_IN` として独立する。
- 抵抗R6・R9/R10とコンデンサC14の内部ノードは省略。**`OSC_IN` と `CLK` は直結しない**。選択スイッチはWebアプリで2Hz/10Hzを切り替える既存操作に対応する。
- シミュレータでは `OSC_IN` の閾値判定後の理想論理値を `CLK` と同相、`OSC_INV` を逆相とする。CRの実電圧、RC遅延、シュミット閾値、発振時の短い過渡現象は模擬しない。
- RESET用のD/Eゲート、手動クロック用のAゲート、未使用のFゲートはすべて配線・プローブ対象から外す（74HC14の未使用入力は実基板では浮かせず定電位に固定する）。
- `RST_N` を共有するCPU側のレジスタ/フリップフロップは保持し、74HC14のピン10のみ `RST_N` から除外する。物理RESET回路は本アプリの対象外。

## ROM接続

- 74HC154(U13)：A0..A3は **23,22,21,20**、イネーブルは **18,19→GND**。
- アクティブLOW出力 `ROM_SEL_0..10` は U13.1..11、`ROM_SEL_11..15` は U13.13..17。
- ROMは1番地8bit、計16番地。各番地の8スイッチは同じ選択信号に**機能的**に属する。ただしダイオードを挟むため、選択線・各スイッチ下側端子・データ列は電気的に直結ではない。
- 74HC540(U12)：`OE1#(1)`・`OE2#(19)`→GND。ROMデータ列は、添付PDFの配線方向に合わせて **A7(9)=ROM_RAW0、A6(8)=ROM_RAW1、…、A0(2)=ROM_RAW7** と定義。出力は **Y7(11)=D0、Y6(12)=D1、…、Y0(18)=D7**。
- PDFの8連DIPスイッチを踏襲した場合、スイッチの各bit `b` の**上側端子番号は9+b**（例：bit0=9、bit7=16）。下側端子は**8-b**（bit0=8、bit7=1）。上側は全番地で共通の `ROM_RAWb` 列につながる。下側は各セル独立で、ダイオード経由でその番地の選択線に対応する。

ROMの論理データは `D0..D7`（74HC540の**反転出力**）。ROM_RAWとDを同じ電気ネットにしてはいけない。スイッチがONの場合、選択されたROM行がRAW列をLOWに引き込み、インバータ後に論理1となる関係としてモデル化する。ROMアドレス選択LEDは `ROM_SEL_i=LOW` で選択中とする。

## クロック、リセット、I/O、LED

- クロック：添付のCLOCK/RESET回路図から**自動CR発振のB・Cゲートだけを採用**。手動クロック・外部クロック・RESET用ゲートは使用しない。74HC14(U2).6をCPU共通の `CLK` へ接続し、U2.4とU2.5を `OSC_INV` の同一電気ネットとする。抵抗・コンデンサを通る帰還経路は同一ネットには結合しない。
- リセット：今回は74HC14のEゲート（U2.11→U2.10）は使用せず、U2.10を `RST_N` から外す。CPU側の `RST_N` は論理モデル上Hで保持し、Webアプリの電源操作でCPU状態を初期化する。実基板では解除状態を保証するプルアップ等を別途検討する。
- INPUT：`IN0..IN3` はスイッチの論理出力と74HC153のI2入力が共有するネット。電源/GND側の実端子は回路方式を確定するまで保留。
- OUTPUT：`OUT0..OUT3` はU5 Q0..Q3から出力端子へ接続する。LEDは電流制限抵抗を介して観測する**関連表示**として扱う（LED端子とOUTネットの直結は未確定）。
- ICのVCC/GND端子はそれぞれ単一の共通電源ネット。スイッチやパイロットLED、アナログRC回路の完全な物理配線は本版の対象外。

## 現行コードとの差と次の実装に必要なこと

1. 74HC540のビット順はPDFのU12に合わせ、物理ピンY7=D0、Y0=D7として採用済み。
2. 74HC74はPDFのB側（8〜13番）をキャリーFFに採用済み。/Q(8)=`C_N`をデコードに接続する。
3. 74HC161のENP/ENTと、74HC32（4ゲート）・74HC10（3ゲート）の全物理端子を`netlist.json`に登録済み。IC詳細画面も`gateGroups`を参照し、入力と出力をゲート別に表示する。
4. 未完了なのは74HC14のCR受動部品端子・未使用ゲートの入力固定方法、INPUT/OUTPUTやROMの受動部品・スイッチ端子などの細部。PDFから未確定の直結は作らない。
5. **物理ピンはJSONを正本として表示。** `pnpm run build` が `assets/js/data/netlist.js` を自動生成し、`physicalPins()` と74HC32/10のゲート詳細がその定義を参照する。CPUの命令実行ロジックは従来どおり独立する。

## 表示上の注意

**電気ネット** と **機能的な信号関係** は区別する。

- 電気ネット：同一銅配線で常時直結される端子のみまとめる。
- スイッチ：閉じた状態の接点だけ接続される。
- ダイオード：信号伝搬はするが入出力を同一ネットに統合しない。
- 抵抗/LED：論理信号との関連表示として扱い、同一ネットへ強制統合しない。
- IC内部の入力→出力：内部論理の結果であり直結ではない。

この区別を守ると、ROMスイッチを操作しても無関係な行・列が「同一信号」としてハイライトされない。

## Webアプリの利用方針（2026-11）

- **接続の正本**は `src/data/netlist.json`。PDFを基準に端子・ネットを定義し、実装で同じ接続表を二重管理しない。
- `assets/js/data/netlist.js` はビルドで生成する公開用の読み取り専用データ。手動編集しない。
- ICの物理DIP脚はJSON `pinNets` / `pinNames` をそのまま表示。抵抗・ダイオード・スイッチ・IC内部回路越しの信号は別ネットを維持する。
- ROMスイッチは上側の共通 `ROM_RAWn` 列へ所属させ、旧実装の「選択中だけ `Dn` に接続」とする疑似表示を廃止。下側は独立 `ROM_CELL_addr_bit` を保持するが、別端子として描画する機能は今後の課題。
- `src/core/ic-circuit.ts` の `chips`・`layout` はCPUの**機能的な論理プローブ**。物理配線ではない。FFの論理値・命令実行は変えない。
- 74HC74はPDFのB側を使用。Q(9)は未結線、/Q(8)を `C_N` とする。74HC540のビット順はPDF準拠、出力イネーブル(1,19)はGND固定とする。
- 74HC14は自動CR発振のB・Cゲートだけを接続する（U2.3/4/5/6）。RESET・手動・外部CLK用ゲートは使用せず、CR受動部品越しの端子を直結しない。74HC32/74HC10はPDF上の全ゲート接続を登録済み。その他の未確認箇所は推測せず、JSONに情報がない脚を未モデル化として表示する。
