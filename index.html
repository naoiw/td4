TD4 命令セットオリジナル12命令 · 8bit構成とIC制御信号⌄

機械語の上位4bitで命令を分類し、下位4bitに即値 Im（0〜15）または固定値0を指定します。命令ごとのレジスタ動作と回路のH/L信号を並べて確認できます。

命令ビット（固定） 即値ビット（i3〜i0） H = HIGH L = LOW
命令Hex 8bit 機械語 C実行後 制御信号（H / L）

MOV A, Im0x3n 0011i3i2i1i0 0 HHLHHH
即値 Im を A レジスタへ転送する。実行前の C は参照せず、実行後 C=0。
MOV B, Im0x7n 0111i3i2i1i0 0 HHHLHH
即値 Im を B レジスタへ転送する。実行前の C は参照せず、実行後 C=0。
MOV A, B0x10 00010000 0 LHLHHH
B レジスタの値を A レジスタへ転送する。実行前の C は参照せず、実行後 C=0。
MOV B, A0x40 01000000 0 LLHLHH
A レジスタの値を B レジスタへ転送する。実行前の C は参照せず、実行後 C=0。
ADD A, Im0x0n 0000i3i2i1i0 0/1 LLLHHH
A レジスタに即値 Im を加算し、下位4bitを A に書き込む。実行前の C は参照せず、桁あふれ時に実行後 C=1。
ADD B, Im0x5n 0101i3i2i1i0 0/1 LHHLHH

IN A0x20 00100000 0 HLLHHH
入力ポートの4bitを A レジスタへ転送する。実行前の C は参照せず、実行後 C=0。
IN B0x60 01100000 0 HLHLHH
入力ポートの4bitを B レジスタへ転送する。実行前の C は参照せず、実行後 C=0。
OUT Im0xBn 1011i3i2i1i0 0 HHHHLH
即値 Im を出力ポートへ転送する。実行前の C は参照せず、実行後 C=0。
OUT B0x90 10010000 0 LHHHLH
B レジスタの値を出力ポートへ転送する。実行前の C は参照せず、実行後 C=0。
JMP Im0xFn 1111i3i2i1i0 0 HHHHHL
即値 Im が示すROM番地へ無条件にジャンプする。実行前の C は参照せず、実行後 C=0。
JNC Im0xEn 1110i3i2i1i0 0 HHHHHL/H
実行前 C=0 なら Im の番地へジャンプし、C=1 なら次の番地へ進む。Ld3 は旧C=0で L、旧C=1で H。実行後 C=0。

Cは命令実行後のキャリーフラグ。ADDのみ演算結果で0 / 1に変わります。JNCの分岐判定には実行前のCを使用します。

Ld0〜Ld3はアクティブLOW（Lで書き込み有効）、順にA・B・OUT・PCの制御信号です。JNCのLd3は旧C=0ならL、旧C=1ならHです。

ここにない機械語もハードウェアのデコードに従って実行できますが、オリジナルの標準12命令には含めていません。ICの伝搬遅延や接点チャタリングは模擬しません。
