TD4 命令セットオリジナルの12命令と機械語の対応を確認⌄
命令オペコード処理
ADD A, Im0x0nA ← A + Im
MOV A, B0x10A ← B
IN A0x20A ← IN
MOV A, Im0x3nA ← Im
MOV B, A0x40B ← A
ADD B, Im0x5nB ← B + Im
IN B0x60B ← IN
MOV B, Im0x7nB ← Im
OUT B0x90OUT ← B
OUT Im0xBnOUT ← Im
JNC Im0xEnC=0ならPC ← Im
JMP Im0xFnPC ← Im

Imは4bit即値（0〜F）。キャリーは全命令でALUの加算結果から更新されます。*付き表示はオリジナルの12命令に含まれない機械語で、実機のデコード回路に従って動作します。シミュレーションは命令単位であり、74HC素子の伝搬遅延や接点チャタリングは模擬しません。
